### How the Owner Can Replace These Photos

1. To update any photo, simply place your photo in `public/images/` using the matching filename (e.g. `swimming-pool.webp` or `villa-pool-1.webp` / `villa-pool-1.jpg`).
2. WebP format is recommended for lightning-fast mobile loading.
3. No React components or code edits are required.
